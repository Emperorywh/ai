# 视觉诊断与制作选择

在固定机位的同画幅下观察。优先解决屏幕占比大、轮廓明显、影响空间层次的缺陷；“看起来很空”先检查空间结构与可见性，不先堆随机细节。

## 机位记录与对照

最小记录包含：参考文件、坐标/单位、位置、forward/up 或明确欧拉顺序、透视/正交、FOV 所指轴、画幅、近远裁面、默认启动视角。需要跨工具同步时，机位名和参数从同一配置读取，避免 Blender、场景和运行脚本各存一份不一致的数值；本轮不涉及机位同步时沿用可靠的现有机位机制。

水平与垂直视角换算：`vFov = 2 * atan(tan(hFov / 2) / aspect)`；计算时注意角度/弧度。正交视图应记录覆盖宽高而不是套用透视焦距。不要把 SC01 的位置、75°水平视角或12米制作高度当作通用地面镜头。

从参考选少量稳定锚点，并记为左上原点的归一化图像坐标：地平线、近景道路入口、主要转折、主峰、林带边缘等。人工锚点用于诊断，不是精确摄影测量；画面一致性不能仅用一个总误差数字代替判断。

检查相机是否被动画、时间线标记、运行期控制器或默认帧覆盖。SC01 曾出现设好的相机被旧时间线标记切回，导致观察与导出不一致。保存后独立重开源文件，并核对运行时实际相机参数。

## 从症状选择修改对象

| 可见症状 | 先检查 | 常用修改方向 | 无效捷径 |
| --- | --- | --- | --- |
| 道路显宽、湖显小、山显近 | 机位位置、FOV、画幅与遮挡 | 校准镜头，再依据尺寸约束改布局 | 直接缩窄道路、压扁山体 |
| 山像排列的帐篷或圆锥 | 主脊/支脊、谷底、肩部和前后山系 | 不同尺度峰团、分叉谷地、宽雪盆与局部岩壁 | 加同频噪声或统一细分 |
| 雪地像平板，雪包像卵石 | 大地形与雪堆的接地关系 | 大尺度缓坡，中尺度堆雪/雪坎，小尺度断边与压痕 | 只有法线贴图，或摆大量球体 |
| 岸线像整齐护栏/台阶 | 截面连续性、高程和水位 | 变化的坡宽、高度、缓入水与短陡坎，局部土石草雪交错 | 给规则边缘叠一层随机颜色 |
| 林带数量多却没有色块 | 相机可见范围、树冠覆盖和坡面 | 连续但有缺口的林群、疏密和层次 | 均匀撒点、每株都导出独立高模 |
| 草灌存在但画面看不见 | 投影位置、像素大小、遮挡和埋雪深度 | 在最终机位可见的地形变化处配置少量簇，检查侧视接地 | 增加远处数量，或无限放大叶片 |
| 水没有晚霞/整片粉色 | 反射方向、天空亮区、Fresnel、法线、曝光 | 蓝色底层与局部暖反射并存，波纹打散明暗 | 全水统一加粉色、仅提高反射增益 |
| 明暗层次弱、雪显灰/白片 | 主光、环境光、阴影、曝光与材质线性值 | 统一冷暖光，保留远近对比及局部厚度阴影 | 直接全局提亮或过强腔隙效果 |

## 山体样段应证明什么

需要看到连续主脊、尺度不同的峰肩、方向不同的支脊、汇合谷地、前后遮挡，以及雪盆与陡岩的不同坡面关系。建立主形后，再决定何处露岩、何处积雪。

高度场适合能以单值高程表示的地形；陡壁、悬挑、冰推或复杂岸石可能需要独立网格。选择和混用表示方式，不能为了脚本简单把所有对象强塞进一个高度函数。

SC01 的具体失败值得识别：

- 点/线距离控制的峰脊包络产生相似尖峰，强主坡吞掉较弱支脊。
- 约束剖分提高了控制，但线性插值仍留下大片平面；加非线性断面后又可能变为圆滑雪丘。
- 更密的沟蚀与少数短岩肋没有自动建立完整地貌结构，材质下仍像刻痕。
- 仅降低露岩遮罩阈值，会把平滑雪丘涂灰，不能产生岩壁。

这些是方法选择的警示，不是对 Blender Python 的能力上限判断。若换用高程数据，先确认覆盖区域、水平/垂直单位、分辨率、无数据值、坐标和来源；放大低分辨率数据不等于恢复真实细节。艺术近似与地理复原分别标注。

## 植被与近岸：先可见，再精细

中景林带先匹配深色面积、外轮廓、沿坡方向和雪地空隙，之后才增加树型差异。小样导出前就确定共享原型、实例变换与区域归属的表示，避免后期返工。

草灌、岸石与雪堆从最终地表采样接地；地形更新后重新核对，不能保留旧高程。观察视角变化，检查有没有埋没、悬浮、穿路、穿水、重复锯齿或均匀环形边缘。近景可见像素和局部阴影比对象数量更能说明效果。

## 天空、照明和水面的共同方向

用同一世界方向约定定位天空亮区、主光及水反射，核对全景旋转、前向天空扇区、立方体面向和纹理坐标；独立调旋转容易出现天空亮在左、反射亮在右。

水的底色、深度变化、法线、粗糙度、Fresnel 和环境反射分工明确。近处水纹应可辨识，远处亚像素波纹应衰减或转入粗糙度/反射模糊，避免摩尔纹。高处与低处、透视与正交分别核对，不把主机位遮住的着色错误留到游览时暴露。

列清真实能力：天空贴图不是自动的 HDR 光源；天空环境反射不包含山体；深度透明不等于真实折射。需要额外反射方式时，依据目标引擎、后端和实际画面选择，先做小范围发布验证。
